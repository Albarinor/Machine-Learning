4. 定义4种分类模型¶

本实验对比以下4种分类方法：

  1. Logistic Regression（逻辑回归）- 线性模型
  2. SVM（支持向量机）- 核方法
  3. Random Forest（随机森林）- 集成学习
  4. KNN（K近邻）- 基于距离的分类
In [5]:
models = {
    'Logistic Regression': LogisticRegression(random_state=42, max_iter=1000),
    'SVM (RBF)': SVC(kernel='rbf', random_state=42),

5. 训练并评估4种模型¶

训练所有模型并记录准确率、精确率、召回率、F1分数和训练时间。

In [7]:
results = []
all_predictions = {}

print("\n开始训练4种模型...")
print("-"*60)

for name, model in models.items():
    start_time = time.time()
    
    model.fit(X_train_scaled, y_train)
    y_pred = model.predict(X_test_scaled)
    all_predictions[name] = y_pred
    
    train_time = time.time() - start_time
    
    acc = accuracy_score(y_test, y_pred)
    prec = precision_score(y_test, y_pred)
    rec = recall_score(y_test, y_pred)
    f1 = f1_score(y_test, y_pred)
    
    results.append({
        '模型': name,
        'Accuracy': acc,
        'Precision': prec,
        'Recall': rec,
        'F1-score': f1,
        '训练时间(秒)': train_time
    })
    
    print(f"\n【{name}】")
    print(f"  准确率: {acc:.4f}")
    print(f"  精确率: {prec:.4f}")
    print(f"  召回率: {rec:.4f}")
    print(f"  F1分数: {f1:.4f}")
    print(f"  训练时间: {train_time:.4f} 秒")

print("-"*60)
print("所有模型训练完成！")

11. 实验结论与总结¶

11.1 实验结果总结¶

本实验使用4种分类方法对威斯康辛州乳腺癌数据集进行分类，主要结论如下：

模型 Accuracy Precision Recall F1-score 训练时间
Logistic Regression 98.25% 98.61% 98.61% 98.61% 0.006秒
SVM 98.25% 98.61% 98.61% 98.61% 0.006秒
Random Forest 95.61% 95.89% 97.22% 96.55% 0.24秒
KNN 95.61% 95.89% 97.22% 96.55% 2.14秒

11.2 分析讨论¶

  1. 最佳模型：逻辑回归和SVM表现最好，准确率98.25%
  2. 最快模型：SVM和逻辑回归训练最快（约0.006秒）
  3. 关键发现：在这个数据集上，简单模型（逻辑回归、SVM）反而比复杂模型（随机森林、KNN）表现更好
  4. KNN较慢：因为需要计算所有样本之间的距离

11.3 结论¶

乳腺癌数据集的特征与标签之间存在较强的线性关系，因此逻辑回归这类线性模型就能取得很好的效果。对于实际医疗诊断应用，建议优先使用逻辑回归或SVM，它们不仅准确率高，而且训练速度快。
